# Rota ANPD

App de estudos do Jullio para o concurso de Especialista em Regulação de Proteção de Dados da ANPD.

- Site instalável (PWA): https://rota-anpd.vercel.app
- `src/`: código-fonte (versão do Claude Artifact, com fallback para navegador)
- `public/`: site publicado (gerado por `node build.js`, requer `terser` e `clean-css`)
